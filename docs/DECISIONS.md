# Decisions

One line per decision: date, decision, reason.

| Date | Decision | Reason |
|---|---|---|
| 2026-11-11 | Use installed Flutter 3.41.6 / Dart 3.11.4 and do not upgrade | It is the toolchain on this machine; the package set is verified against it |
| 2026-11-11 | Drop `custom_lint`; enable `riverpod_lint` as an analyzer plugin | The two do not resolve together on this SDK; current `riverpod_lint` no longer uses it |
| 2026-11-11 | Hold `riverpod_generator` 4.0.3, `riverpod_annotation` 4.0.2, `flutter_riverpod` 3.3.1 | Later versions need `meta` 1.18 or Dart 3.12, and Flutter pins `meta` 1.17.0 |
| 2026-11-11 | Minimum Android is API 24, not 23 | Flutter 3.41.6's Android engine declares minSdk 24 and its tooling migrates lower values upward |
| 2026-11-11 | Use `SemanticsService.sendAnnouncement` instead of `announce` | `announce` is deprecated and would break zero-warning analysis |
| 2026-11-11 | No Flame; widgets plus `CustomPainter` | Required by the brief; a turn-based board needs no game loop |
| 2026-11-11 | `domain/` is innermost and `data/` depends on it | `domain/` must be pure Dart, while `data/` needs Flutter plugins |
| 2026-11-11 | `AnimationQueue` drives animations through a `GameAnimator` port | `application/` cannot import `presentation/`; also enables a fake in tests |
| 2026-11-11 | Dice are counter-based: `face(seed, index)` using SplitMix64 | Keeps `GameEngine.roll` pure, makes resume trivial, avoids dependence on `Random`'s algorithm |
| 2026-11-11 | Engine resolves a whole roll atomically; `GameState.phase` rests at `awaitingRoll` or `gameOver` | Intermediate phases are display concerns exposed by `GameViewState` |
| 2026-11-11 | Autosave right after the engine returns, before animating | A crash mid-animation can never lose a roll |
| 2026-11-11 | `GameState.history` is capped at 256 events | Bounded save size and fast simulations; full replay is possible from the seed |
| 2026-11-11 | `Jump.path` holds interior control points only | §5.5 adds head and tail centres; the §3.4 sample's final point would duplicate the tail |
| 2026-11-11 | Snake art design letter derives from rank | Avoids changing the specified board JSON schema |
| 2026-11-11 | A turn includes its extra rolls | Defines `stats.turns` and the simulation metric |
| 2026-11-11 | A 6 blocked by overshoot still grants the extra roll | Literal reading of "rolling a 6 gives another roll" |
| 2026-11-11 | The third 6 does not move the token | The penalty ends the turn immediately |
| 2026-11-11 | Captures made earlier in a turn stand after a three-6s revert | Simplest consistent rule; only the mover is reverted |
| 2026-11-11 | A finishing 6 grants no extra roll | The player has finished |
| 2026-11-11 | Need-a-6 moves the token to square 1, switchable through `kNeedSixEntersAtSquareOne` | Required by §5.4 |
| 2026-11-11 | In v1 bot levels differ only in thinking delay | No current rule offers a player a choice; `BotStrategy.chooseAction` is the seam |
| 2026-11-11 | Quick Play uses default rules and the Settings default snake count | §1.3 says default rules; §1.2 says the default count comes from Settings |
| 2026-11-11 | A win for unlocks is a completed game whose first finisher is human, in any mode | The brief does not restrict unlocks by mode |
| 2026-11-11 | Snake heads render in their own layer above the cached board | The gulp animation would otherwise invalidate the cache every frame |
| 2026-11-11 | Tapered snake bodies are filled ribbons built from path samples | Flutter strokes have constant width |
| 2026-11-11 | Board cross-fades with `AnimatedSwitcher`; UI through `themeAnimationDuration` | Bitmap variants cannot be interpolated |
| 2026-11-11 | App name Snake Saga, bundle id `com.dawnplay.snakesaga` | Brief defaults, confirmed by "go" at the Phase 1 gate |
| 2026-11-11 | Classic Sunshine's simulation floor is 18 mean turns; other boards keep 20–45 and target 25–40 | Classic's fixed layout averages 19.64 at 6 snakes under default rules |
| 2026-11-11 | Entering at square 1 through need-a-6 never triggers a jump | Otherwise every player on Classic would enter at 38 through ladder 1→38 |
| 2026-11-11 | vs Computer needs at least 1 human and 1 bot; Pass & Play is all human with the toggle hidden | Reconciles §1.3 with the "4 players with 2 bots" wireframe |
| 2026-11-11 | At the start of Phase 4, delete the default `linux`, `macos`, `web`, `windows` folders and run `git init` | Brief targets Android and iOS only and requires commits |
| 2026-11-11 | Sugar Rush and Jungle Temple layouts are generated by `tool/wireframes/design_boards.mjs` (seeded) and written to `assets/boards/` | Reproducible search that enforces the validator, balance and art constraints together |
| 2026-11-11 | Sugar Rush targets 26–35 and Jungle Temple 30–38.5 mean turns per player at every snake count | Inside the brief's 25–40; Jungle is harder because it unlocks later |
| 2026-11-11 | Snake bodies keep clear of other jumps' end points: 0.26 tile around heads and ladder feet, 0.16 tile around tails and ladder tops, plus body half-width (0.16 → 0.06 tile) | Makes "never cover a head or foot" measurable; checked at 8 snakes, so it holds at 6 and 7 |
| 2026-11-11 | Generated boards have no snake crossing another snake; ladders are straight, steeper than 1.5:1, and do not cross each other | Readability; near-flat ladders read poorly |
| 2026-11-11 | Snake curves are uniform Catmull-Rom with end points duplicated, converted to cubic Béziers (`toBeziers` in `tool/wireframes/geometry.mjs`) | The Dart painter must reproduce exactly the curve the layouts were validated against |
| 2026-11-11 | Wireframes are generated from the board JSON by `tool/wireframes/build_wireframes.mjs` | Sheets and JSON cannot drift apart |
| 2026-11-11 | Player Setup shows the selected board with a "Change" link to Board Select | Snake preview needs a board; avoids an extra step in the flow |
| 2026-11-11 | Reset stats keeps unlocked boards unlocked (pending confirmation) | Losing boards on a stats reset feels punishing |
| 2026-11-11 | Art is authored as SVG by code in `tool/assets/` (sources in `assets_src/`), exported to PNG by `tool/export_assets.py` with resvg | Reproducible, consistent style across ~370 assets; one script regenerates everything |
| 2026-11-11 | Brief pixel sizes are the 2x export (tile 128 → 64 logical, dice and avatars 256 → 128); `board_bg` 3x is 1080 × 2340 | Matches Flutter's resolution-aware loading, where 1x is logical size |
| 2026-11-11 | Text in SVG sources is converted to paths with opentype.js | Sources render identically in resvg, browsers and the library page without font files |
| 2026-11-11 | Dark-mode snakes and ladders use a pale outline instead of a dark tint | Dark outlines measured 1.0–2.8:1 on night tiles; pale rims reach at least 4.0:1, matching the light rim on tokens and dice |
| 2026-11-11 | Ladder rails tile the 12 × 64 strip along the ladder | Stretching distorted candy-cane stripes and vines |
| 2026-11-11 | Badges, token and dice shadows: badges in light/dark; the two shadows are a single file used in both modes | A 25% black shadow reads on both palettes |
| 2026-11-11 | Launcher icon and native splash sources live in `assets/launcher/` and are not bundled | Build inputs for flutter_launcher_icons and flutter_native_splash only |
| 2026-11-11 | All audio is synthesised by `tool/synth_audio.py` and released as CC0; music is 22.05 kHz mono, Vorbis q −1 and AAC 18 kbps | Meets the 150 KB limit for a 60 s loop; encoder overshoot is measured and corrected to ≤ −1 dBFS |
| 2026-11-11 | `ref/classic_board_reference.png` was never supplied; Classic Sunshine follows the brief's written description and hex values | Unblocked Phase 3 |
| 2026-11-11 | Text on Leaf, Coral and Sky is Ink; Leaf labels are at least 19 px Fredoka 600 | White fails contrast on all three; Ink on Leaf is 4.43:1, so it must qualify as large text |
